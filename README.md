# cds-app-fresh

Fresh workspace created by assistant. Replace this with your project files or scaffold new projects.

Development scripts

See the `scripts/` folder for helper scripts that start the API and frontend together during development:

- `scripts/start-dev.ps1` — Windows PowerShell helper (prompts to kill port if needed).
- `scripts/start-dev.sh` — POSIX shell helper for macOS/Linux/Git Bash.

Run `./scripts/start-dev.sh` on Unix-like systems or the PowerShell script on Windows to launch both services.
